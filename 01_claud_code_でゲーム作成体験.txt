01_claud code でゲーム作成体験
---------------------------------------------------
以下の設定でテキストアドベンチャーゲームをPythonで作成してください。

【世界観・設定】
- 舞台：近未来の都市（2080年代ごろ）
- 主人公：目覚めたら記憶がない人物（名前・過去・目的すべて不明）
- ジャンル：SFミステリー
- 雰囲気：謎解き・推理・緊張感・ストーリーをバランスよくミックス

【ゲーム仕様】
- ターミナル上でテキスト表示（日本語対応）
- 部屋・場所は5つ程度（例：廃病院の一室、薄暗い路地、監視カメラだらけの地下鉄駅など）
- アイテムを拾って調べたり使ったりできる
- 選択肢式（番号で選ぶ）
- 謎を解くと断片的に記憶が戻っていく演出
- クリアエンディングとバッドエンディングを1つずつ
- コードは拡張しやすいよう、場所・アイテム・イベントをデータとして分離した構造にしてください

【言語】
Python 3（外部ライブラリなし、標準ライブラリのみ）
---------------------------------------------------
今のPythonのテキストアドベンチャーゲームを
HTML/CSS/JavaScriptでブラウザで動くビジュアルゲームに作り直してください。

【要件】
- 単一ファイル（index.html）にまとめる
- 近未来のSFミステリーらしいデザイン（暗めの背景・近未来フォント・青や緑の差し色）
- テキストは1文字ずつ表示されるタイプライター演出
- 選択肢はボタンで選べるようにする
- スマホでも見られるレスポンシブ対応
